## Production Validation Decision

`dbt build --target prod` was not validated locally. The local `prod` profile
uses `method: service-account-json`, but this workstation is currently
authenticated through OAuth ADC and the service-account JSON profile is not
usable locally.

For this release track, production validation is accepted through successful
scheduled `Weekly Data Refresh` runs. Those runs exercise the production refresh
path, build the public release artifacts, and publish the weekly data releases.

Local `prod` target validation remains useful as an operator convenience, but
it is not a release-blocking gate for `v1.0.0-rc.1` or final `v1.0.0` while the
scheduled refresh path remains healthy.

## Recommendation

Proceed with `v1.0.0-rc.1`.

If the RC does not reveal a regression, proceed to final `v1.0.0` without an
additional local `prod` target gate.
